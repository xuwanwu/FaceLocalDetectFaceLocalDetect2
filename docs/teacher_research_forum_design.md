# 温州市第十四高级中学 · 教师教科研论坛（“十四高教科研论坛”）

面向校内教师的教研 + 科研一体化平台，支持交流讨论、成果沉淀、课题管理与资源共享，可与钉钉群聊形成互补：钉钉侧重即时沟通，本平台侧重体系化管理与公共展示。

## 1. 目标与定位
- **可见、可找、可积累**：让教师教研成果有序沉淀，便于检索与复用。
- **教研组主页**：每个教研/备课组有固定线上空间，支撑日常活动与评优材料沉淀。
- **课题全流程管理**：覆盖申报、立项评审、过程记录、中期检查、结题评审与成果展示。
- **激励机制**：积分与荣誉墙提升参与度与荣誉感，逐步形成学校教科研知识库。

## 2. 角色与权限
- **教师 (Teacher)**：浏览公开内容、发帖/编辑/删除本人帖与评论、上传论文/课件/案例、以成员身份加入课题、查看个人档案与积分。
- **教研/备课组长 (GroupLeader)**：拥有教师权限；可置顶本组帖子、审核本组资源；维护本组主页介绍、计划、总结。
- **校级管理员 (Admin/教科研处)**：站点配置、栏目管理、用户与角色管理、课题立项与结题审核、精华与首页推荐、数据统计。
- **专家/校外导师 (Expert，可选)**：评审课题/论文/活动；在指定板块发“专家专栏”。
- **学生/访客 (可选)**：只读，浏览公开成果与活动报道。

## 3. 功能模块
### 3.1 首页（门户）
- 顶部 Banner：校徽+站点名称+导航。
- 轮播区：重要通知、重点课题、活动宣传。
- 快捷入口：教研组空间、课题管理、论文与案例库、研修活动。
- 最新动态：按时间的最新帖子、按推荐的精华帖。
- 成果展示：近期结题课题、获奖论文/微课/竞赛。
- 数据看板：本学期发帖数、参与教师数、课题数、活动次数等。

### 3.2 论坛板块（交流讨论）
- 按“教研主题 + 学科”双维度建板块，如课堂教学与评价、作业设计与学业质量、数字化赋能课堂、班级管理与德育实践、高考命题与备考、教科研方法与论文写作、以及语文/数学/英语等各学科组。
- 帖子：标题、正文（图文+附件）、所属板块、标签；评论/楼中楼、点赞、收藏、搜索与标签筛选；精华/置顶由管理员或组长维护。

### 3.3 教研组空间（学科主页）
- 组简介：组长、成员、教研理念。
- 年度计划与总结文档。
- 本学科活动：教研活动记录、公开课安排、磨课记录。
- 资源：本组教师上传的课件、试卷、案例、课堂实录；小组公告。
- 主页可导出用于评优材料。

### 3.4 课题管理（核心流程）
1) **课题申报**：在线填报名称、负责人、成员、预期成果、方案、时间节点等；上传申请书。
2) **立项评审**：管理员查看申报列表，标记立项/不立项/修改后再议，生成立项清单。
3) **过程管理**：按课题维护工作日志、阶段成果、调研报告；上传会议签到、照片、PPT 等资料。
4) **中期检查**：提交中期报告与佐证材料，记录评审意见。
5) **结题管理**：提交结题报告、成果汇编、发表论文；记录专家评审，标记“已结题/优秀/示范”等等级。
6) **成果展示页**：面向校内/公众展示课题摘要、负责人、成果简介。

### 3.5 论文与资源库
- 资源类型：论文、课堂教学案例、课件、试卷与命题分析、微课视频/课堂实录。
- 上传：标题、摘要、关键词、学科、学段、文件上传；管理员审核后公开。
- 检索：按学科、年份、资源类型、关键词搜索；收藏与下载统计；与个人档案联动。

### 3.6 研修与活动
- 活动列表：名称、时间、地点、主讲人、主办单位、参与对象。
- 在线报名与签到（预留对接钉钉/班牌接口）；资料下载与回放；活动反馈表单；记录纳入个人研修档案。

### 3.7 个人主页与教科研档案
- 基本信息：姓名、学科、职称、任教年级、教研组。
- 我的发帖、课题（负责人/成员）、论文成果（期刊/时间/等级/证书）、获奖情况、研修记录。
- 教科研积分或活跃度等级展示，支持导出年度总结。

### 3.8 荣誉墙与数据统计
- 荣誉墙：优秀课题负责人、教科研积极分子、优质课/教学大赛获奖、年度“教科研之星”。
- 数据分析：发帖数量走势、课题立项/结题数量、活动次数与参与人次、按学科的发帖与成果分布。

### 3.9 后台管理
- 用户与角色管理；论坛板块管理；课题分类与级别设置；资源类型管理；帖子/资源/活动审核；系统设置（Logo、首页轮播、公告）。

## 5. 页面交互示例（文字版）
- **首页（PC）**：固定顶部导航；主视觉 Banner + 标语；右侧展示本周教研活动预告；三栏区块（最新帖子、优秀课题/论文推荐、数据简报）；下方教研组入口与最新活动回顾。
- **帖子列表页**：顶部板块名称与说明；左侧发帖与过滤（标签、时间、精华）；右侧列表显示标题、标签、作者、时间、回复数、浏览数、精华标记；分页或无限滚动。
- **课题详情页**：标题与级别标签；负责人、教研组、起止时间；课题摘要与研究方案（可折叠）；阶段成果时间线（立项说明、中期报告、相关活动、结题报告与附件）；参与教师名单。
- **个人教科研档案页**：顶部头像/姓名/学科/职称/教研组；中部选项卡（课题、论文与案例、教研发帖、研修活动）；右侧活跃度雷达或统计。

### 6.2 核心数据表（示例字段）
- `users`：id, name, subject, role, title, group_id, email, password_hash, created_at
- `boards`：id, name, type, description, parent_id
- `topics`：id, board_id, title, content, author_id, created_at, updated_at, is_sticky, is_featured
- `topic_comments`：id, topic_id, author_id, content, parent_comment_id, created_at
- `research_projects`：id, title, level, leader_id, group_id, status, start_date, end_date, summary
- `project_members`：id, project_id, user_id, role
- `project_docs`：id, project_id, doc_type (proposal/midterm/final/others), title, file_url, created_at
- `resources`：id, type, title, abstract, subject, uploader_id, file_url, tags, created_at, is_public
- `activities`：id, title, start_time, end_time, location, host, description
- `activity_signups`：id, activity_id, user_id, status, sign_in_time
- `honors`：id, user_id, type, title, level, date, description
